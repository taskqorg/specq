# Contributor rules

Read README.md, then only the section you change: caveman/README.md and caveman/rules/core.md for style, engineering/README.md for the contract.
Keep project content in English. One canonical definition per rule; link instead of duplicating thresholds or catalogs. Preserve upstream snapshots unchanged. Record source revisions. Label invented examples. Do not claim style changes are active in another project without integration and rendered-output evidence.
Run `python3 caveman/scripts/check.py` and `git diff --check` before publishing.
