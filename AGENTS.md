# Contributor rules

Read README.md and rules/core.md, then the relevant profile.
Keep project content in English. One canonical definition per rule; link instead
of duplicating thresholds or catalogs. Preserve upstream snapshots unchanged.
Record source revisions. Label invented examples. Do not claim style changes
are active in another project without integration and rendered-output evidence.
Run `python3 scripts/check.py` and `git diff --check` before publishing.
